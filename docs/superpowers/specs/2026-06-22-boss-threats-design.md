# 단계별 보스 위협 시스템 — 설계 문서

작성일: 2026-06-22
대상: `gene-pool-arena-mobile/index.html` (모바일 단일플레이 복사본)

## 1. 목적

유전학 생존 게임에 **단계별 보스 위협**을 추가해 매 판 긴장 곡선과 전략적 깊이를 만든다.
보스는 특정 유전자 풀에 유리/불리하게 작용하여, 게임의 정체성인 **자연선택**을 핵심 공략으로 만든다.

핵심 루프: **경고 → 지형 대피로 빈도 정비 → 보스 소환·추격 → 싸우고/도망치고/번식 반복 → 공략 또는 멸종**

## 2. 선행 변경 — 게임 시간 10분

기존 5분 → **10분**으로 연장. 보스 3마리가 들어갈 여유 + 번식 회복 시간 확보.

| 상수 | 기존 | 변경 |
|---|---|---|
| `METEOR_TIME` | 300000 (5분) | **600000 (10분)** |
| `METEOR_WARN_TIME` | 285000 | **585000** |

`DAY_LENGTH`(60s), `WEATHER_INTERVAL`(25s), `TERRAIN_EVENT_INTERVAL`(10s) 등은 유지.

## 3. 보스 명단 (10종)

유전자는 5종(color R/B, speed S, poison P, armor A, charm C). 10마리 구성:

### 단일 유전자 보스 6 — 지형 대피 1:1
| # | 보스 | 요구 형질 | 대피 지형 | 비고 |
|---|---|---|---|---|
| 1 | 🔥 용암 거인 | R (RR) | 🌋 화산 | 기존 선택압 |
| 2 | 🏜️ 모래 폭군 | B (BB) | 🏜️ 사막 | 기존 선택압 |
| 3 | ❄️ 빙하 군주 | A 갑옷 | ❄️ 눈밭 | 기존 선택압 |
| 4 | ☠️ 독포자 마수 | P 독성 | 🐸 독성늪 | 기존 선택압 |
| 5 | 💨 질풍 추적자 | S 속도 | 💧 강가 | **신규 선택압 오라** |
| 6 | 💗 매혹 포식자 | C 매력 | 🌳 숲 | **신규 선택압 오라** |

### 복합 압력 보스 3 — 두 형질 동시 (고난이도)
| # | 보스 | 요구 형질 |
|---|---|---|
| 7 | 🛡️💨 강철 질주병 | A + S |
| 8 | 🌋☠️ 화염 역병룡 | R + P |
| 9 | 🌊💗 심연 세이렌 | B + C |

### 히든 보스 1 — 초희귀
| # | 보스 | 특이점 |
|---|---|---|
| 10 | 🌈 태초의 포식자 (Primordial) | 최종 슬롯에서 **약 2% 확률** 등장. 단일 형질이 아니라 **유전적 다양성(`calcDiversity`)** 을 요구 — 한 형질 몰빵 시 도태. 대비 방향이 정반대(균형 유지). 처치 시 **고유 돌연변이 + 대량 점수 + 도감 해금** |

**한 판 구성**: 중간보스 2 + 최종보스 1. 1~9번 중 **중복 없이** 무작위 추첨. 최종 슬롯만 2% 확률로 10번 히든이 대체.

### 선택압 오라
강가→S, 숲→C 선택압은 평상시 지형 밸런스를 건드리지 않도록 **해당 보스가 경고/추격 중일 때만** 작동하는 임시 효과로 구현. 6번까지 전부 "유리 지형에 있으면 요구 형질 보유 개체가 도태에서 보호받는다"는 동일 메커니즘으로 통일.

## 4. 흐름 (상태머신) — 추격형

```
idle → warning(예고) → chase(소환·지속 추격) → resolve(공략/게임오버) → idle
```

보스는 짧은 이벤트가 아니라 **소환 후 개체군을 지속 추격하는 개체**다. 죽일 때까지(또는 시간초과 퇴각) 따라온다.

### 타이밍 (10분 기준)
- 중간보스 1: **~2:30**
- 중간보스 2: **~5:30**
- 최종보스: **~8:00** (10:00 운석까지 추격)
- 보스 간 간격은 번식·회복 시간으로 확보

### 단계
- **warning** (20초 카운트다운): 상단 경고 배너(보스명 + 요구 형질 + 대피 지형), 가장 가까운 대피 지형 방향 화살표, 대비도 게이지(요구 형질 현재 빈도 %) 표시. 플레이어는 이 시간에 집단을 유리 지형으로 이동.
- **chase**: 보스 소환. 보스가 집단 중심을 향해 지속 이동. 이동속도는 집단보다 **살짝 느림**(도망 가능, 뒤처진 개체는 따라잡혀 도태).
- **resolve**: 공략 성공 또는 게임오버 판정.

## 5. 핵심 전투 루프 — 싸우고 / 도망치고 / 번식

매 틱(chase 중):
- **접촉 (보스 공격범위 안)**:
  - **도태**: 요구 형질 **없는** 개체가 강한 피해 → 사망 (`hp`/`dead`). 보유 개체는 보호.
  - **반격**: 보스 HP가 범위 안 **요구 형질 보유 개체 수**에 비례해 감소. → 순수 유리 집단으로 붙을수록 보스가 빨리 닳음.
- **도망 (범위 밖)**: 도태 정지. 이때 **번식**(`handleBreed` 기존 그대로)으로 ① 개체수 회복 ② 유리 지형 번식·도태로 요구 형질 빈도↑.
- **재교전**: 빈도 끌어올린 집단으로 다시 붙어 보스 HP 추가 타격.

→ **"도망 → 번식 → 빈도 정비 → 재돌격" 반복으로 보스 HP를 깎아 공략.** 무대비 정면충돌은 도태로 집단 붕괴.

- **복합 보스**(예: A+S): 두 형질 모두 보유 개체만 안전·반격, 하나라도 없으면 도태.
- **히든**(다양성): 다양성 ≥ 기준이면 전체 안전·반격, 낮으면 전체 도태. 반격력 = 다양성 비례.

## 6. 판정 + 보상

- **공략 성공** = 보스 HP 0
  - 중간보스: 점수 + 소량 돌연변이 확률
  - 최종보스: 큰 점수 + 돌연변이 1종 확정 → **운석 피날레 도달**
  - 히든: **고유 돌연변이 + 대량 점수 + 도감 해금**
- **게임오버** = 추격 중 개체수 임계(**3마리**) 미만으로 붕괴 → 멸종 엔딩(결과창 + 그래프 정상 표시)
- **중간보스 시간초과**(예: **90초** 못 죽임) → 보스 퇴각(생존했으나 보상 없음, 손실만). 최종보스는 10:00 운석까지 추격.

보스 관련 주요 시점(소환·도태·처치)은 `recordAlleleSnapshot()` + `showMessage(text, true)`(env 태깅)로 기록 → 기존 결과 그래프에 보스가 빈도에 준 충격이 마커로 자동 표시.

## 7. UI / 연출 (모바일 우선)

- **경고 배너**: 상단 큰 보스 배너 — 보스명 + "요구: 🛡️A" + "대피: ❄️눈밭" (기존 `battle-banner` 스타일 재사용)
- **대피 화살표**: 가장 가까운 대피 지형 방향 화면 가장자리 화살표 (`tutorial-arrow` 패턴 재사용)
- **대비도 게이지**: 요구 형질 현재 빈도 % 실시간 바 (`s-genes` 바 재사용)
- **카운트다운**: warning 20초 숫자/바
- **chase**: 보스 스프라이트 + `cameras.shake/flash`(기존) + 도태 개체 `burst`(기존) + **보스 HP 바(지속 표시)**
- **resolve**: 승/패 연출 + 토스트
- **햅틱**: 경고·도태·승리 시 `navigator.vibrate` (모바일 체감)

## 8. 기존 코드 연결점

- **데이터**: `BOSS_ROSTER`(10종 정의 배열: id, name, ico, 요구 조건 fn, 대피 지형, HP, 보상), `BOSS_SCHEDULE`(타이밍 3슬롯).
- **상태머신**: scene 메서드 `rollBossSchedule`, `startBossWarning`, `bossWarningTick`, `spawnBoss`, `bossChaseTick`, `resolveBoss`. 상태변수 `this.bossPhase`, `this.activeBoss`, `this.bossEntity`(스프라이트/좌표/HP/속도).
- **update() 루프**: `elapsed` 기반 보스 스케줄 체크(운석 체크 옆). 보스 chase 중 `bossChaseTick(dt)` 호출. 보스 활성 중 AI 집단 전쟁 생성 등 일시정지.
- **추격 AI**: 보스 좌표를 집단 중심(`player.x/y`)으로 매 틱 이동. 공격범위 판정(거리 ≤ R) → 도태/반격 토글.
- **도태/반격**: `hasDominant`·`getGenotypeLabel`·`geneFrequency`·`calcDiversity` 재사용. 선택압 오라는 chase/warning 중에만 적용.
- **번식**: 기존 `handleBreed` 그대로.
- **init**: `rollBossSchedule()`(중복없이 3종 + 최종 2% 히든) + 보스 상태 초기화.
- **운석 연동**: 최종보스 생존/처치 → 운석 피날레. 보스 active와 운석 타이밍 겹치면 보스 우선.
- **HTML 추가**: `#boss-banner`, `#boss-hp`, 대피 화살표, 대비 게이지 DOM.
- **상수 변경**: `METEOR_TIME` 600000, `METEOR_WARN_TIME` 585000.
- **도감**(선택, 후속): 이벤트 도감에 보스 10종 탭.

## 9. 범위 밖 (YAGNI)

- 선택 교배(능동 유전 조작) — 이번 보스 스펙에 불포함, 대비는 지형 이동으로만.
- 메타 진행/영구 해금 — 별도 기능.
- Capacitor 패키징 — 별도 작업.

## 10. 조정 가능 숫자 (구현 시 튜닝)

보스 이동속도 배율, 공격범위 R, 도태 피해량, 보스 HP, 카운트다운 20초, 중간보스 퇴각 90초, 게임오버 임계 3마리, 히든 2% 확률, 다양성 기준값.
